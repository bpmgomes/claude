# Revisão de segurança · AF-07

Veredito: APROVADO. Nenhum problema de gravidade alta ou média. `npm audit`: 0 vulnerabilidades. 653 testes passando.

## Problemas encontrados (pendentes, todos de gravidade baixa)

1. Limitador de imagens global não é justo entre usuários: uma conta pode ocupar as 2 vagas e a fila de 4. Limitar a 1 vaga/item por usuário ou chavear por `userId`; tirar da fila requisições cujo cliente desconectou.
2. No PostgreSQL, `markRemoved` e `setPhotoKey` (SELECT + UPDATE sem `FOR UPDATE`) podem deixar arquivo órfão. Usar `UPDATE ... RETURNING` ou `SELECT ... FOR UPDATE` ao portar.
3. Profissionais removidos se acumulam sem teto (~43 mil linhas/dia por conta). Teto incluindo removidos ou limite diário de criações.
4. `/media/professionals/:file` sem rate limit, como `/media/logos`. Tratar no AF-09.
