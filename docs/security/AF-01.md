# Revisão de segurança · AF-01

Veredito: APROVADO. Nenhum problema de gravidade alta ou média. `npm audit`: 0 vulnerabilidades.

## Observações de gravidade baixa (pendentes)

1. `trustProxy: false` em `src/app.js`: atrás de um proxy, o rate limit vira global. Tornar configurável por ambiente.
2. `cookieSecure` só liga com `NODE_ENV=production`. Ligar por padrão e desligar só em dev/testes.
3. bcryptjs (JS puro, custo 12) ocupa CPU por cadastro; rate limit por IP não segura ataque distribuído nem rotação IPv6 no mesmo /64. Considerar bcrypt nativo/argon2 e agrupar IPv6 por /64.
4. Novo cadastro com sessão anterior ativa não revoga a sessão antiga. Tratar no AF-02.
5. `validateName` aceita caracteres invisíveis/bidirecionais (U+200B, U+202E). Opcional: rejeitar `\p{Cf}`.

## Para o AF-02

A proteção contra CSRF hoje depende de SameSite=Lax + só JSON + sem CORS. Reavaliar com token CSRF ou checagem de `Origin`.
