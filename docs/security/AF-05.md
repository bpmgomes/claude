# Revisão de segurança · AF-05

Veredito: APROVADO. Nenhum problema de gravidade alta ou média. `npm audit`: 0 vulnerabilidades (sharp 0.35.5). 338 testes passando.

## Problemas encontrados (pendentes, todos de gravidade baixa)

1. Limite por IP compartilhado entre rotas: `guardsFor()` reaproveita o mesmo array `onRequest`, e o @fastify/rate-limit só executa o primeiro handler. Gerar arrays novos por rota e testar que a checagem de slug não consome o limite do POST.
2. Sem limite de processamentos simultâneos de imagem (pico de ~200 MB com 8 uploads). Semáforo no `processLogo` com fila curta; considerar `MAX_DIMENSION` 2048.
3. Limitador por usuário em memória, por processo. Migrar para store compartilhado quando houver mais de uma instância.
4. Logo com cache de 1 ano (`immutable`). Reduzir `max-age` (ex.: 1 dia).
5. Sequestro de link (R5, aceito): slug antigo liberado na hora. Reavaliar quarentena/redirecionamento antes do AF-09.
6. `slug-availability` ecoa a entrada sem limite de tamanho. Omitir ou cortar quando `INVALID`.

Notas: `/media/logos/:file` sem rate limit (avaliar no AF-09); mensagem do 415 no upload fala em JSON.
